An entry for the [the-catalogue-photo-of-an-2-20261121-0341 bounty on make.fun](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341): a single catalogue photograph of a small impossible device, caught mid-use.

`main.py` writes the photograph to `/output/entry.png` (or to
`$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set). The shot: a
chrome retro toaster, toast popping up, while a tiny umbrella on an
articulated arm shields it from falling rain — a toaster that keeps
your toast dry in the rain. One accessory sharpens the joke: a butter
dish beside it. Clean white studio background, believable chrome,
manufactured, not sketched.

## Run it

```sh
python3 main.py
```

Deterministic: stdlib only, no network, no randomness, no timestamps.
Running it twice produces a byte-identical `entry.png` (1024×683 PNG,
341,697 bytes).
